### Quick start
```bash
cd Cyber-Terrafor-Professional-v7.2
./install.sh
./cyber_terrafor --help
```

Authorized single-target demo:
```bash
./cyber_terrafor
```

Authorized scoped assessment:
```bash
./cyber_terrafor --scope scope.txt adaptive-analysis https://YOUR-AUTHORIZED-DOMAIN
./cyber_terrafor --scope scope.txt deep-audit https://YOUR-AUTHORIZED-DOMAIN
```

Module health:
```bash
./cyber_terrafor --scope scope.txt module-health
```

Reports:
```bash
./cyber_terrafor reports-list
./cyber_terrafor html-report
```
